# 🌿 RelaxiZ

A gentle, private emotional support space built with Flutter.

RelaxiZ is designed for moments when you just need to express what you feel — without judgment, without storage, without pressure.

---

## 💡 Concept

RelaxiZ is not a social network.
It is not a therapy replacement.

It is a **companion app** that simply *stays with you* when you need it.

Users can:

* Share what they are feeling
* Be acknowledged with empathy
* Receive relevant comforting content
* Let their thoughts go — without being saved or tracked

---

## ✨ Features

### 🗣️ Express Freely

* Users can type anything they feel
* No filters, no judgment
* Supports raw emotional expression

### 🤍 Emotional Validation

* App responds with calming, human-like reassurance
* Example:

    * “It’s okay to feel this way.”
    * “You’re not alone in this.”

### 📖 Contextual Support

* Shows:

    * Short relatable stories
    * Gentle reflections
    * Supportive thoughts
* Content adapts based on emotional tone

### 🌬️ Release to Air Mode

* A dedicated space to "let it out"
* Users type and release thoughts
* Nothing is stored
* Symbolic emotional release

### 🔒 Privacy First

* No login required
* No data stored
* No tracking
* Fully ephemeral interaction

---

## 🧠 Philosophy

RelaxiZ is built on three principles:

1. **Feelings are valid** — no emotion is wrong
2. **Expression heals** — saying it helps
3. **Privacy matters** — your thoughts belong to you

## 🚀 Getting Started

### Prerequisites

* Flutter SDK installed
* Android Studio / VS Code

### Installation

```bash
git clone https://github.com/your-username/relaxiz.git
cd relaxiz
flutter pub get
flutter run
```

---

## 📱 App Flow

1. Open app
2. Choose to:

    * Express feeling
    * Release thoughts
3. Type freely
4. Receive:

    * Validation message
    * Optional supportive content
5. Close app — nothing persists
